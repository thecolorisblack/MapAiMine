# Примеры

## Промты, которые работают

### Спавн сервера
```
Сделай спавн сервера: зимняя деревня 120×120 в точке 0,0. Поставь точку спавна на площади,
зафиксируй раннее утро и ясную погоду, отключи спавн мобов и гриферство, поставь границу мира 500.
В конце телепортируй меня туда.
```

### Деревня под конкретный биом
```
Разведай участок 120×120 вокруг 1500,-800. Если там равнина — поставь средневековую деревню
«Ольхово» на 96 блоков, если лес — сначала расчисти площадку. Потом озелени всё вокруг на 30 блоков.
```

### Выбор вайба
```
Построй один и тот же дом в стилях medieval, winter, autumn, japanese и fantasy_elven —
в ряд, с табличками. Потом телепортируй меня посмотреть.
```

### Замок
```
Найди рядом со мной холм повыше, выровняй вершину и поставь замок с крепостной стеной
и воротами. Стиль — nordic.
```

### Отдельный мир под стройку
```
Создай пустой мир buildworld, зафиксируй там полдень и ясную погоду, и построй арену 21×21.
```

### Копирование своей постройки
```
Сними мою постройку с 100,64,100 по 120,90,120 в файл «my_castle» и поставь три копии
вдоль дороги на север с шагом 40 блоков.
```

## Конфиги MCP

`mcp-configs/` — готовые файлы для разных клиентов. Подставь свой токен и путь.

## Свой стиль

`my-style-template.json` — заготовка стиля с минимально необходимыми ролями.
Скопируй в `content/styles/<твой_id>.json`, поменяй блоки, затем:

```bash
cd mcp-server && npm run validate:content
```

Полное описание формата — `docs/SCHEMAS.md`.

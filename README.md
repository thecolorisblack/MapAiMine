# MapAiMine

**Нейросеть строит миры, спавны и деревни в Minecraft.**

MCP-сервер + плагин для Paper/Spigot + библиотека стилей и готовых построек.
Скажи «сделай спавн в зимнем стиле» — и он появится на сервере.

</div>

---

## Что это

Три части, которые работают вместе:

```
       ты                нейросеть              MapAiMine MCP            Minecraft
  «сделай зимний  ──►  Claude / Codex /  ──►   стили, блюпринты,  ──►   плагин-мост
   спавн 120×120»       Antigravity …          генератор поселений       (Paper/Spigot)
                                                                              │
                                              ◄── разведка рельефа ───────────┘
```

| Часть | Где | Что делает |
|---|---|---|
| **MCP-сервер** | `mcp-server/` | 30 инструментов для ИИ: разведка, стройка, генерация поселений, отмена |
| **Плагин-мост** | `plugin/` | HTTP-API внутри сервера: ставит блоки по тик-бюджету, читает рельеф, умеет откат |
| **Библиотека** | `content/` | 11 стилей и каталог построек — не привязаны к блокам, один дом рисуется любым стилем |
| **Скилл** | `skills/` | объясняет нейросети, что она в режиме билдера и как правильно действовать |

Зачем: **не покупать билдеров и не строить самому**. Спавн, деревня, город, замок,
арена, порт — генерируются за минуты, откатываются одной командой.

## Стили (вайбы)

| id | Вайб |
|---|---|
| `medieval` | средневековая деревня: булыжник, дуб, фахверк |
| `winter` | снег, лёд, ель, костры — зимний вайб |
| `spring` | сакура, азалия, пастель, цветы |
| `summer` | яркая зелень, песчаник, бамбук, вода |
| `autumn` | мангр, терракота, подзол, тыквы, сено |
| `nordic` | викинги: длинные дома, дёрновые крыши |
| `japanese` | пагоды, сакура, бамбук, бумажные фонари |
| `desert` | песчаник, глина, плоские крыши, оазис |
| `fantasy_elven` | светлое дерево, кварц, аметист, свечение |
| `steampunk` | медь всех стадий, кирпич, цепи, лампы |
| `modern` | бетон, стекло, кварц, минимализм |

Свой стиль — это один JSON-файл, см. `docs/SCHEMAS.md`.

## Что умеет ИИ через MapAiMine

* **Разведать** участок: карта высот в ASCII, биомы, вода, ровность, рекомендуемая высота застройки.
* **Сгенерировать поселение**: площадь, сетка улиц, дома фасадами к дороге, фонари, крепостная
  стена с воротами, озеленение. `village` / `town` / `castle` / `camp` / `farmstead` / `harbor`.
* **Поставить отдельное здание** из каталога в любом стиле, с поворотом и подготовкой площадки.
* **Изменить рельеф**: выровнять, сгладить, поднять, террасировать, расчистить.
* **Оформить пейзаж**: покрасить землю, рассыпать траву, цветы, деревья, камни, снег.
* **Настроить мир**: создать новый (в т.ч. пустой «холст»), время, погоду, gamerules, границу.
* **Поставить спавн**, телепортировать игрока, написать в чат.
* **Снять постройку игрока** в файл и копировать её куда угодно.
* **Откатить** любую стройку.
* **Витрина стилей**: один дом в 5–10 стилях в ряд с табличками — чтобы выбрать вайб глазами.

## Быстрый старт

```bash
git clone https://github.com/thecolorisblack/MapAiMine
cd MapAiMine

# 1. Плагин
cd plugin && mvn -B package        # → target/mapaimine-bridge-0.1.0.jar
cp target/*.jar /путь/к/серверу/plugins/
# запусти сервер, возьми токен из plugins/MapAiMine/config.yml

# 2. MCP-сервер
cd ../mcp-server && npm install && npm run build
MAPAIMINE_TOKEN=токен npm run doctor      # проверка связи

# 3. Подключить к нейросети (пример — Claude Code)
claude mcp add mapaimine --env MAPAIMINE_TOKEN=токен \
  -- node $(pwd)/dist/index.js
cp -r ../skills/mapaimine ~/.claude/skills/
```

Подробно — **[docs/QUICKSTART.ru.md](docs/QUICKSTART.ru.md)**.
Конфиги для Codex, Antigravity, Cursor, Windsurf, Cline, VS Code, Gemini —
**[docs/AGENT_SETUP.md](docs/AGENT_SETUP.md)**.

## Без плагина (режим RCON)

Если плагин поставить нельзя (ванильный сервер, хостинг без доступа к `plugins/`) —
MapAiMine работает через RCON: строит, ставит спавн, настраивает мир. Но **не видит мир**:
недоступны разведка, откат, создание миров, покраска и рассев.
Таблица возможностей — в `docs/PROTOCOL.md` §3.

## Безопасность

* Плагин слушает `127.0.0.1` и требует токен. Наружу порт открывать не нужно.
* Каждая стройка пишет снимок для отката (`undo_last`).
* Лимиты на объём операции и на регион — и в плагине, и в MCP-сервере (`MAPAIMINE_MAX_BLOCKS`).
* Стройки идут по тик-бюджету: сервер не фризится даже на миллионах блоков.
* `MAPAIMINE_READ_ONLY=1` — режим «только смотреть».
* Опасные команды (`run_command`) можно отключить в конфиге плагина.

## Требования

* Minecraft-сервер Paper/Spigot/Purpur **1.20.6+** (собрано против API 1.21.4), Java 21
* Node.js 20+
* Любая нейросеть с поддержкой MCP

## Вклад

Самое ценное — **новые стили и постройки**: это просто JSON, код писать не нужно.
```bash
cd mcp-server && npm run validate:content   # проверит всё перед PR
```
